Open dashboard

Keep this computer running. Use a private network and allow iR-Board through Windows Firewall for private networks only.

Tablet cannot connect? In the iR-Board desktop window, click Allow tablet access through Windows Firewall and accept the Windows permission prompt. Set your trusted home network to Private in Windows network settings. Both devices must use the same LAN; guest Wi-Fi, client isolation and VPNs can block access. Try another computer address above if a VPN or virtual adapter is listed.
